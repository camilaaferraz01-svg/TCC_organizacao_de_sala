COMO FUNCIONA

Regras do projeto

Um sistema simples para incentivar a organização das salas no período da manhã.

01

O Grêmio avalia

Os integrantes do Grêmio realizam as avaliações das salas.

02

As salas pontuam

Cada avaliação gera uma pontuação de acordo com a organização.

03

O ranking atualiza

Os pontos acumulados definem a posição de cada turma.

04

Todos acompanham

Os alunos podem visualizar o ranking, mas não podem alterar avaliações.
